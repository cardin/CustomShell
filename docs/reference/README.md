# Reference documents

Detailed normative text for specific subjects. The canonical record set is one
level up: [requirements](../REQUIREMENTS.md), [design](../DESIGN.md),
[interfaces](../INTERFACES.md), [test plan](../TESTPLAN.md), and
[decisions](../ADR.md).

- [Install.md](Install.md) — setup, upgrade, options, persistent environment,
  and known limitations.
- [Protect-Tar.md](Protect-Tar.md) — archive command behavior, format,
  portability, failure safety, and version history.
- [Mirror-Win-Ssh.md](Mirror-Win-Ssh.md) — WSL SSH mirror behavior, safety, and
  permissions.

These are reference records, not change-local specifications. Requirements and
interfaces link here for detail; changes follow the same workflow as the living
records.
