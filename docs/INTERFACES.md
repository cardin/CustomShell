# CustomShell interfaces

This document defines the contracts other work depends on: entry points,
command signatures, configuration schemas, environment variables, generated
files, and exit status. See [requirements](REQUIREMENTS.md) for essential
outcomes and [design](DESIGN.md) for implementation. The
[command references](reference/README.md) cover detailed command behaviour.

Public command names and startup paths are compatibility surfaces. Changes to
signatures, managed file paths, or configuration keys must update the affected
contracts and document compatibility impact; see the
[change guidance](../AGENTS.md#change-guidance).

## Entry points

| Surface | Contract |
| --- | --- |
| `pwsh/main.ps1` | Sourced by the managed all-hosts profile. Composes startup files, loads `pwsh/Settings.psd1`, and exports module commands. |
| `linux/main.sh` | Sourced by the managed `.bashrc` block. Composes startup files, defines commands, and may start the SSH agent. |
| `~/.config/customshell/env.sh` | Generated by Linux startup. Safely quoted `sh` assignments, sourced by the managed `~/.profile` block. |
| `~/.config/environment.d/90-customshell.conf` | Generated by Linux startup for the systemd user session. `KEY=value` lines only. |

The profile block is delimited and rewritten in place:

```text
# >>> CustomShell >>>
...
# <<< CustomShell <<<
```

Linux also writes this block to `~/.profile`:

```text
# >>> CustomShell profile >>>
...
# <<< CustomShell profile <<<
```

An unmarked manual `source` line is never treated as managed state.

### Environment publication

Linux startup publishes only present, valid managed values. It updates each
file atomically, skips unchanged files, and preserves the previous contents
if publication fails.

## Commands

| Command | Platforms | Contract |
| --- | --- | --- |
| `Protect-Tar` | PowerShell, Bash | Create an encrypted archive. See [command interface](reference/Protect-Tar.md#command-interface). |
| `Unprotect-Tar` | PowerShell, Bash | Decrypt and extract an archive. See [command interface](reference/Protect-Tar.md#command-interface). |
| `Get-SSHConfig` | PowerShell | Read concrete OpenSSH host aliases. |
| `Show-Help` | PowerShell, Bash | Print the compact interactive command reference. |
| `mirror-win-ssh` | WSL | Replace `$HOME/.ssh` from `$USERPROFILE/.ssh`. See [Mirror-Win-Ssh.md](reference/Mirror-Win-Ssh.md). |
| `list_cert_chain` | Linux | Print the TLS chain for `HOST [PORT]`; default port `443`. Requires `gnutls-cli`; missing host exits `2`, missing tool exits `1`. |
| WSL wrappers | PowerShell on Windows | One alias per `WslCommands` entry when the alias name is free. |

### Protect-Tar and Unprotect-Tar parameters

The documented CLI form is:

```text
Protect-Tar <source> [output_base] [--exclude <pattern>]... [--no-ignore]
Unprotect-Tar <archive.enc> [destination]
```

PowerShell exposes named parameters; positional use follows the same order.

| Documented | PowerShell | Bash |
| --- | --- | --- |
| `<source>` | `-Source` (position 0) | `$1` |
| `output_base` | `-Output` | `$2` |
| `--exclude <pattern>` | `-Exclude <string[]>` | `--exclude <pattern>` (repeatable) |
| `--no-ignore` | `-NoIgnore` | `--no-ignore` |
| `--help` | `-Help` / `-h` (also accepts `--help`) | `--help` |
| `<archive.enc>` | `-Archive` (position 0) | `$1` |
| `destination` | `-Destination` (default `.`) | `$2` (default `.`) |

Both commands publish only after validation, packaging, and encryption or
decryption have succeeded. A handled failure is non-zero: the Bash functions
return non-zero and the PowerShell functions throw. A help request succeeds
without touching the filesystem. Passphrases are read by `age`; they are never
command parameters.

### Get-SSHConfig

```powershell
Get-SSHConfig [-ConfigPath <string>]
```

`ConfigPath` defaults to `$HOME/.ssh/config`. The command returns one object per
non-wildcard alias, sorted by `Alias`, taking `HostName`, `User`, and `Port`
from that alias's `Host` block. A missing config file produces a warning and
no output. The parser is read-only and does not process `Include`, expand
wildcards, or implement full OpenSSH precedence.

### WSL command wrappers

`WslCommands` in `pwsh/Settings.psd1` names commands to expose. A string uses
the same name in PowerShell and WSL. A hashtable with `Command` and `Alias`
sets the WSL command and PowerShell alias separately. For each entry, when `wsl`
exists and the alias would not shadow a native command or foreign alias,
startup creates:

- function `Invoke-Wsl<PascalName>` (for example `Invoke-WslOpencode`);
- a global alias pointing at that function.

The default exposes `opencode` as `opencode-wsl`. The profile no longer creates
a plain `opencode` alias, leaving that name available for native OpenCode.

The wrapper runs:

```text
wsl -e env CUSTOMSHELL_SUPPRESS_STARTUP_OUTPUT=true bash -lic '<command> "$@"' _ <args...>
```

Wrappers from a previous load are removed first, so removing an entry or
installing a native command takes effect on the next profile load.

## PowerShell module

`pwsh/Modules/CustomShell.Commands/CustomShell.Commands.psd1` is the public
surface. Importing the module must not run profile setup or change external
configuration.

| Manifest key | Value |
| --- | --- |
| `ModuleVersion` | `2.0.0` |
| `PowerShellVersion` | `7.0` |
| `FunctionsToExport` | `Get-SSHConfig`, `Unprotect-Tar`, `Protect-Tar` |
| `CmdletsToExport` | none |
| `VariablesToExport` | none |
| `AliasesToExport` | none |

Any new exported command must use an approved PowerShell verb.

## Settings schema

Windows settings are a PowerShell data file, `pwsh/Settings.psd1`:

| Key | Type | Meaning |
| --- | --- | --- |
| `StartTimeoutSeconds` | number | Slow-start diagnostic threshold. |
| `Prompt` | string | `ohmyposh`, `starship`, or `none`. |
| `WslCommands` | array of strings or hashtables | [WSL commands and their PowerShell aliases](#wsl-command-wrappers). |
| `RequiredCommands` | string[] | Optional commands reported when missing; never fatal. |

Linux settings are arrays in `linux/Settings.sh`:

| Variable | Meaning |
| --- | --- |
| `CUSTOMSHELL_REQUIRED_COMMANDS` | Optional commands reported on every platform. |
| `CUSTOMSHELL_NON_WSL_REQUIRED_COMMANDS` | Optional commands reported only on native Linux. |

Overrides accepted by setup (for tests and unusual layouts) are documented in
[Install.md](reference/Install.md#linux-and-wsl-options) and
[Install.md](reference/Install.md#windows-options).

## Environment variables

### Installer-owned

| Variable | Platforms | Contract |
| --- | --- | --- |
| `GTK_OVERLAY_SCROLLING` | Linux | `0`, traditional GTK scrollbars. |
| `UV_SYSTEM_CERTS` | Both | `true`, use the platform certificate store. |
| `WSLENV` | Windows | `USERPROFILE/up`. |
| `CONDA_PATH` | Windows | Directory containing `conda.exe`, when found; an existing valid value stays unmanaged. |
| `STARSHIP_CONFIG` | Windows | Repository Starship theme while `Prompt = 'starship'`; cleared otherwise. |

### Runtime-managed

| Variable | Platform | Contract |
| --- | --- | --- |
| `BROWSER` | WSL | Generated Windows-browser wrapper; an existing value is kept. |
| `USERPROFILE` | WSL | Derived through `cmd.exe` and `wslpath` when absent. |
| `SSH_AUTH_SOCK`, `SSH_AGENT_PID` | Linux | Published by the reusable SSH agent. |
| `OMP_THEME` | Linux | Oh My Posh theme name for the current terminal context. |
| `STARSHIP_CONFIG` | Linux | Selected Starship theme path. |
| `NODE_EXTRA_CA_CERTS`, `REQUESTS_CA_BUNDLE` | Linux | Set from a valid `CUSTOM_CA_CERT` only. |
| `CUSTOMSHELL_SUPPRESS_STARTUP_OUTPUT` | Both | Suppresses interactive startup output for wrappers and nested shells. |

## Generated and state files

| Path | Owner | Purpose |
| --- | --- | --- |
| `%LOCALAPPDATA%\CustomShell\environment.json` | Windows setup | Values set and still owned. |
| `%LOCALAPPDATA%\CustomShell\installed.txt` | Windows setup | Tracked installed configuration files. |
| `%LOCALAPPDATA%\CustomShell\clink.json` | Windows setup | Previous and managed Clink state. |
| `${XDG_STATE_HOME:-~/.local/state}/customshell/git-credential-helper` | Linux setup | Previous Git credential-helper values. |
| `~/.config/environment.d/90-customshell.conf` | Linux startup | systemd user environment. |
| `~/.config/customshell/env.sh` | Linux startup | POSIX login-shell environment. |
| `~/.cache/customshell/ssh-agent.env` | Linux startup | Reusable agent variables. |
| `~/.cache/customshell/windows-browser` | WSL startup | `BROWSER` wrapper. |

Files in these locations are managed state. Uninstall removes only state it
still owns and reports locally modified state instead of deleting it.

## Exit status and diagnostics

| Surface | Contract |
| --- | --- |
| `--check` / `-Check` | Non-zero when required setup state is missing or stale. Optional or missing commands never change the status. |
| `--dry-run` / `-DryRun` | Never changes the filesystem; reports intended actions. |
| `Protect-Tar`, `Unprotect-Tar` | Success publishes exactly one output. A handled failure before publication leaves no output; a cleanup failure after publication is reported non-zero with the output present. |
| `mirror-win-ssh` | `0` on success, non-zero on validation or publication failure. |
| `list_cert_chain` | `0` on success, `1` when `gnutls-cli` is unavailable, `2` on missing host. |
